*cubrid.txt*                   CUBRID for Neovim

The plugin uses the shared CUBRID language server for completion and syntax
diagnostics. It never executes SQL. Neovim 0.12.5 is the tested version.

SETUP                                                        *cubrid-setup*

Call require('cubrid').setup(options) from trusted user Lua before opening a
file. Each call replaces all previous options. Unknown or invalid options
raise an error and leave the last valid settings in effect.

server_path       Absolute server executable. Omit to use
                  cubrid-language-server on the editor host's PATH.
file_extensions   Dense list of exact suffixes ".sql" and ".csql". Default
                  { ".sql", ".csql" }; a single suffix selects only that
                  extension, and {} disables both. Matching filenames ignores
                  case. The list replaces the defaults. Reopen existing files
                  after changes. Replace the old sql option with this list.
parser_worker     Absolute path to the qualified native worker.
runtime_prefix    Absolute path to its matching runtime. Set both paths.
                  Omit both to discover the worker and runtime from the
                  selected server installation metadata. The plugin reads
                  native/parser-worker/build/parser-worker and its adjacent
                  manifest.json under the recorded source directory. The
                  manifest supplies runtimePrefix. just sync does not build
                  the worker. Wheel or index installs and removed local builds
                  require explicit native paths.
worker_manifest   Optional absolute manifest path. Requires the native pair.
worker_timeout    Positive seconds up to 300. Requires the native pair.
profile           Nonempty parser profile override.
script_mode       "sql" or "csql".
config_path       Absolute metadata configuration path.
schema_snapshot   Omit to inherit project metadata, use vim.NIL to disable,
                  or set an absolute snapshot path.

The plugin warns about observed conflicting filetypes and attached foreign LSP
clients. It does not change their state. If the server is missing, install it
on Neovim PATH or set server_path, then run :CubridRestart.

Explicit executable paths come only from this Lua configuration. The plugin
starts one server using an argv array and shares it across CUBRID buffers.
The server discovers metadata independently for each file. On Neovim 0.12.5,
an unnamed buffer uses URI file://. The current server searches for its
metadata from the parent of the initialize root, which is the editor current
directory when the server starts.

COMPLETION                                                *cubrid-completion*

In Insert mode, press CTRL-X CTRL-O, select with CTRL-N, and accept with
CTRL-Y. CTRL-Y applies the full supported edit, including text after the
cursor. CTRL-E cancels. Space or Escape can discard the menu while leaving a
native preview suffix in the buffer. The plugin owns the buffer-local
omnifunc while its CUBRID client is attached. On detach it restores the previous value only if
the value still belongs to the plugin. Other completion clients keep their
own handlers. The menu uses CUBRID server results only.

The adapter supports plain, single-line text edits whose range contains the
request cursor. Multiline edits, snippets, insert/replace edits, commands,
additional edits, and items requiring resolution are reported as unsupported.
For example, an unclosed quoted identifier at the end of a file can return a
multiline edit. The adapter does not show a partial menu for such a response.
If the buffer changes while a request is pending, the response is discarded.
If an edit invalidates a visible menu, the plugin cancels it and reports the
cancellation. A stale refusal after native insertion preserves the current
buffer text and does not claim that the server edit was applied.

:CubridReloadSchema                                       *:CubridReloadSchema*
    Reload snapshots and report availability and stale state per document.
    A failed reload retains the last valid metadata.

:CubridDoctor                                                   *:CubridDoctor*
    Report the selected installation, active client, diagnostics, and LSP
    log. Run a private syntax diagnostic probe with a fixed SQL document.
    :checkhealth cubrid shows the same report. The Lua function
    require('cubrid').doctor() returns a report table for headless use.

:CubridRestart                                                 *:CubridRestart*
    Stop and restart the owned language server. Use this command to retry a
    missing or failed server. A changed server_path also triggers a restart.

The native server reports unsupported coverage and runtime failures as
diagnostics. An empty diagnostic list does not certify all SQL. Highlighting
and indentation are lexical and do not format or validate SQL.
